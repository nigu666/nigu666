## 正在做的项目

### AI 修图智能体

一个可在本机安装的中文 AI 修图工作台：上传素材，在悬浮画布中编辑图层，确认 AI 计划后执行，预览候选并导出图片。

![AI 修图智能体运行画面](https://raw.githubusercontent.com/nigu666/ai-picture-editor/main/docs/images/workbench.png)

- **实现范围**：React / Konva 画布、FastAPI 接口、LangGraph 规划、本地图片处理、百炼模型接入与 Docker 本机安装交付。
- **我的参与**：需求取舍、模型方案选择、界面反馈和功能验收；通过 AI 协作推进实现，持续补充对代码和工程流程的理解。
- **当前版本**：v0.1.0，Windows x64 + Docker Desktop。云端 AI 需自行配置百炼密钥，当前提供本机使用版本。

[查看源码](https://github.com/nigu666/ai-picture-editor) · [下载安装包](https://github.com/nigu666/ai-picture-editor/releases/latest) · [开发过程](https://nigu666.github.io/ai-application-engineer-portfolio/#picture-process)
